Welcome to the Docker Infrastructure

This is an example public application that's part of the Docker infrastructure setup with Traefik, OAuth2, and API services.

You can access this page without authentication, but the protected resources require OAuth2 login.

Go to Protected App

Infrastructure Components

  • Traefik: Handles routing, SSL, and middleware
  • OAuth2 Proxy: Provides authentication for protected services
  • API Service: Backend service with token authentication
  • PostgreSQL: Database for persistent storage
  • Redis: Cache for improved performance
