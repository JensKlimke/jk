# Whoami

A TypeScript web application that returns HTTP request and server information in JSON format. This service provides details about the server environment and incoming HTTP requests, making it useful for debugging and monitoring.

## Key Features
- Returns server information (hostname, IP addresses) and request details
- Generates and stores a unique application ID in MongoDB
- Follows service-oriented architecture principles
- Provides structured logging with Winston

## Quick Start
```bash
# Install dependencies and build
npm install && npm run build

# Run the application
npm start
```

For detailed documentation on architecture, API endpoints, configuration options, and deployment instructions, please refer to the documentation in the `docs` directory.
